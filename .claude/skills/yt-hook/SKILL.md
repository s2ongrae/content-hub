# yt-hook — 첫 문장 채점

원본: Jakeschincariol/youtube-agent-skill (MIT) `skills/yt-script/hookscore.py` → 한국어 보정판.

```bash
python3 tools/yt/hookscore_ko.py --hook "봉명동 1인 14,000원 냉삼, 웨이팅 16팀 뚫은 이유"
python3 tools/yt/hookscore_ko.py hooks.txt          # 한 줄에 하나, 순위로
python3 tools/yt/hookscore_ko.py --json hooks.txt   # 다른 스크립트에 넘길 때
```

## 계산

- 5속성 0~100. **최종점수 = 평균 60% + 최약 40%**. 최약 가중은 의도적이다. 넷이 세고 하나가 죽은 훅은 그 하나에서 새고, 평균은 그걸 숨긴다.
- 공식 21개는 `seeds/skills/hook_formulas_ko.json`(데이터). 분류는 '문장에 어떤 말이 있는가'의 판정이지 조회수 예측이 아니다.
- 한국어 기준 띠: **65 이상 튼튼 / 50 이상 쓸 만함 / 그 아래 약함**. (영어 원본은 72/55)
- 한국어 어절 7~20이 첫 2초~10초 대역. 20을 넘으면 두 문장으로 쪼개고 하나를 버린다.

## 절차

1. 후보를 **5개** 쓴다. 하나만 쓰지 않는다.
2. `hookscore_ko.py`로 돌려 상위 2개를 **점수·공식·최약속성**과 함께 보여준다.
3. 가장 약한 속성의 코칭 한 줄을 적용해 1개를 고쳐 다시 채점한다.
4. 고른 훅을 `yt-script`로 넘긴다.

## 하지 않는 것

- 점수를 올리려고 숫자를 지어내지 않는다. 확인 못 한 값은 `[가격: 미확인]`으로 남긴다.
- 높은 점수를 "터진다"고 말하지 않는다. 낮은 점수는 "다시 보라"는 신호일 뿐이다.
- 발행하지 않는다. 문장을 쓰고, 사람이 올린다.
