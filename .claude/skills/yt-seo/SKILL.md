# yt-seo — 설명·태그

원본: `skills/yt-seo` (MIT).

## 순서

1. 첫 두 줄: 이 영상이 무엇이고 누구에게 쓸모 있는지. 검색 결과에서 보이는 부분이다.
2. 본문 3~5줄: 확인한 사실(가게·가격·시간·동선)을 문장으로. 숫자는 확인한 것만.
3. **노릴 검색어 3개**를 정하고, 그중 하나를 첫 두 줄에 자연스럽게 넣는다.
4. 태그: 5~8개. **태그는 거의 중요하지 않다** — 이 팩은 그렇게 말한다. 태그 생성기를 팔지 않는다.
5. 위치·블로그·클립 링크(있으면)를 넣는다. 고정댓글에 블로그 주소를 다는 2단계 규칙은 그대로.

## 게이트

- 확인 못 한 값을 설명란에 쓰지 않는다.
- 검색량 수치를 주장하지 않는다. 자동완성은 '수요가 있다'는 증거일 뿐이다.
