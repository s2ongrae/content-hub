# yt-package — 제목 + 썸네일 한 쌍

원본: `skills/yt-package/title.py` (MIT) → 한국어판(폭 기준).

```bash
python3 tools/yt/title_ko.py --title "…" --thumb "1인 14,000원"
python3 tools/yt/title_ko.py titles.txt --thumb "…"      # 한 줄에 하나, 점수순
```

## 도구가 강제하는 규칙

- 길이는 글자 수가 아니라 **폭**이다(한글 1자 = 폭 2). 데스크톱 폭 60(한글 약 30자), 모바일 폭 40.
- **썸네일은 제목을 반복하지 않는다.** 다른 단어, 같은 약속.
- 썸네일 3단어·폭 22 이하(1080px 한 줄).
- 대문자 강조 2개까지. 이모지 2개까지.
- **숫자·이름·날짜 하나**가 형용사 전부를 이긴다.
- 앞 세 어절이 군더더기면 주어를 앞으로.

## 절차

1. 제목 10개를 쓴다 → 전부 린트 → 상위 3개를 **점수와 구체 지적**과 함께 보여준다.
2. 이긴 제목에 썸네일 브리프를 붙인다: 표정, 프레이밍, 3단어, 피드 크기에서 대비를 버티는 배경.
3. 네이버 블로그용이면 제목 공식을 따로 적용한다(`daejeon-content` 스킬): `[지역 동네] 상호 + 솔직후기 : "한 줄 카피"`.

## 게이트

- 쓰기만 한다. 바꾼 제목은 사람이 확인하고 올린다.
- 숫자를 지어내지 않는다. 확인 못 한 값은 괄호로 남긴다.
