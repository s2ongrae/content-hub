# yt-plan — 주간 편성

원본: `skills/yt-plan` (MIT). 이 채널의 실제 리듬: **11/18~12/01 하루 1편 교차(대전청년 → 메리, 12:00)**.

## 짜는 법

1. 이번 주에 실제로 쓸 수 있는 시간을 먼저 적는다(촬영 가능한 날, 편집 가능한 저녁).
2. **앵커 1편** — 시간이 가장 많이 드는 것. 시리즈 번호가 붙는 편.
3. **저비용 1편** — 이미 있는 사진·영상·메모로 만드는 것.
4. **숏폼 3편** — 앵커에서 파생(`yt-shorts`)하거나 현장에서 바로 찍는 것.
5. 시간이 모자라면 앵커를 줄이지 말고 저비용을 늘린다. 앵커가 채널의 약속이다.

## 출력

요일 · 채널 · 편 번호(`DY-…`/`KM-…`) · 촬영/편집 필요 시간 · 막는 조건(팩트 미확인 등).
`content-hub` `#/series` 시드와 대조해 이미 잡힌 편을 중복으로 넣지 않는다.

## 게이트

- 계획만 쓴다. 일정을 바꾸려면 사람이 정한다.
