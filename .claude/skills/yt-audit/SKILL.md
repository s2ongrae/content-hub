# yt-audit — 채널 점검

원본: `skills/yt-audit` (MIT). 원칙: **스무 개 대신 하나.**

## 보는 것

1. 최근 10편의 첫 문장 → `yt-hook`으로 채점, 가장 약한 속성의 분포를 본다(대개 호명 또는 손실).
2. 최근 10편 제목·썸네일 → `yt-package`로 중복·숫자 없음이 반복되는지.
3. 발행 리듬 → 시리즈 번호가 이어지는지, 끊긴 곳이 있는지.
4. 아웃라이어(`yt-viral`) → 평소의 2배가 넘은 편이 어떤 공식을 썼는지.
5. 채널별 자막·음량 규격(`seeds/skills/shorts_preset.json`) 위반이 반복되는지.

## 출력

- 지금 고칠 것 **1개** (근거 수치와 함께)
- 그다음 1개 (이번 달 안에)
- 손대지 말 것 (지금 잘 되고 있어 건드리면 안 되는 것)

## 게이트

- 진단만 한다. 채널 설정을 바꾸지 않는다.
