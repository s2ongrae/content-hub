# yt-script — 대본

원본: `skills/yt-script` + `yt-shorts` (MIT). 프리셋: `seeds/skills/shorts_preset.json` (기본 `daangn-local-v1`).
말투: `seeds/skills/voice_kimseongrae.md` — 담백한 구어체, 충청도 어미 남발 금지, 여백.

## 먼저 읽는 것

1. `seeds/skills/voice_kimseongrae.md` — 소리 내어 읽었을 때 어색하면 그 문장은 버린다.
2. `seeds/skills/shorts_preset.json` — 비트 6개와 자막·컷 규격.

## 모양 (프리셋 고정)

| 구간 | 할 일 |
|---|---|
| 0.0–2.0 | 현장 클로즈업 1컷 + 훅. 인물 정면 금지, 첫 컷 1.0초 안 |
| 2.0–5.0 | 한 문장 약속 — 무엇을 알게 되는지. 인사·구독 요청 금지 |
| 5.0–12.0 | 증거 1 — 확인한 숫자(가격·중량·대기). 3~4컷 |
| 12.0–18.0 | 증거 2 + **실제로 겪은 단점 1개** |
| 18.0–22.0 | 페이오프 — 약속한 것을 명시적으로("이게 답입니다") |
| 22.0–25.0 | 요청 하나. 두 개면 둘 다 안 한다 |

- 자막: 한 줄 12자, 2줄까지. 말과 똑같은 문장을 자막으로 쓰지 않는다.
- 러닝타임: 어절 수 ÷ 분당 150어절. 25초를 넘으면 비트를 줄이거나 문장을 자른다.
- 화면 지시는 `[ON SCREEN: …]`으로 비트마다 붙인다. 말만 있는 비트는 팟캐스트다.

## 절차

1. `yt-hook`으로 첫 문장을 정한다(5개 → 상위 2개 → 1개).
2. 확인한 값만 채운다: 가격·대기·총액·단점. 없으면 `[채우기]`.
3. 프리셋 비트에 말·화면·자막을 채우고, `yt-hook`으로 첫 문장을 다시 채점한다.
4. `yt-package`로 제목·썸네일 한 쌍을 만든다. `yt-edit`로 촬영본 컷을 뽑는다.

## 게이트

- 쓰기만 한다. 업로드는 사람이 한다.
- 숫자를 지어내지 않는다. 확인 못 한 숫자는 자막에도 넣지 않는다.
