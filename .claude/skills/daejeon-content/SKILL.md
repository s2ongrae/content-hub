# 대전 청년 · 삐약 김메리 콘텐츠 제작 기준

성래 님의 두 브랜드 콘텐츠를 쓸 때 **항상** 이 기준을 따른다. 이 파일은 실행용 요약이고,
숫자의 원본은 `docs/CONTENT_STANDARD_v2.md` + `seeds/render_standard_v2.json`(+ `seeds/prompt_rules_2026w47.json`)이다.
**숫자를 바꿔야 하면 이 파일이 아니라 그 세 곳을 같이 고친다.** 어긋나면 문서·시드가 우선.

## 0. 트랙을 섞지 않는다

| 트랙 | 채널 | 특징 |
|---|---|---|
| 🍺 대전 청년 `daejeon_youth` | 블로그(`youth-daejeon`) · 쇼츠(`@daejeon_daily`) · 릴스(`@daejeon_daily`) · 클립 | 맛집·술집·대전 일상만. 2단계 순환(숏폼 3종 → 블로그 → 고정댓글에 블로그 URL) |
| 🐱 삐약 김메리 `ppiyak_kimmary` | 쇼츠(`@s2ongrae`) · 릴스(`@m2ow.mari`) · 클립 | 메리 소재만. 블로그 `SKIPPED`, 업로드 즉시 `LINKED` |

메리 소재는 메리 트랙에만, 대전 맛집·일상은 대전 청년 트랙에만. 인스타는 대전 청년 계정이 **맛집 전용**이다.
인스타는 릴스와 피드 카드뉴스를 따로 센다(피드는 블로그 발행 뒤 D+1~D+2).

## 1. 대전 청년 블로그 (`youth-daejeon`)

**톤 — 가장 자주 틀리는 부분**
- 화자는 20대 후반~30대 대전 청년 집사. 친한 동네 형이 소주 한잔하며 썰 푸는 담백한 구어체(`~요`/`~네요`).
- **충청도식 화법 = 사투리 어미가 아니다.** `~유`/`~혀유` 남발 금지. 느긋한 여백 + 반어적 극찬 + 대전 로컬 비유(성심당 줄, 대전 트램, 1호선)로 유쾌하게.
- 자폭 유머(마이너스 통장, 주식 파란불, 웨이팅 고생)는 한 스푼. 억지 칭찬·광고 티 금지, 아쉬운 점(웨이팅·주차)은 솔직하게.
- 상호·가격·영업시간은 **실측만**. 확인 못 한 값은 `[ ]` 팩트 슬롯으로 남기고 채우지 않는다.

**제목 공식(2단)**: `[지역 동네 메뉴/키워드] 상호명 솔직후기 : "본문 찰진 한 줄"`
예) `[대전 봉명동 고기집] 석암생소금구이 야장 솔직후기 : "계좌도 파랗고 소주도 파랗고"`

**본문 7단계**: 도입 썰 → 외관·웨이팅 → 메뉴·가격 → 기본찬/킬링반찬 → 메인 먹방 → 필승 먹조합 → 총평 박스+정보.

**서식 — 줄글 금지(핵심)**
- 2~3문장마다 줄바꿈. 벽돌글은 즉시 반려된다.
- `━━━━━━` 구분선, `┌───┐` 테두리 박스(메뉴판·꿀팁·총평), 굵게(Bold) 핵심, 문맥 이모지(🤤🥩🔥📸💡🍻).
- 사진·영상 자리마다 `[📸 사진 위치 : …]` + `▲ 한 줄 감성 캡션` 1:1 매핑. 세로 영상은 `[🎬 세로 영상 위치 : …]`.
- 총평 박스: 맛·킬링반찬·가성비·웨이팅·재방문 별점. 이어 위치·영업시간·주차 + **네이버 지도(스마트플레이스) 첨부** + 해시태그 10~12개(대형 3 + 로컬 5 + 메뉴 3).
- 분량 1,500~2,500자(공백 제외). 제목 키워드를 본문에 5~7회 자연 노출.
- 대표 커버 1080×1080: 실사 배경 + 굵은 헤드라인 + 하단 코스 3줄. `VOL.05` 같은 번호 칩·잡스티커 금지.

## 2. 대전 청년 쇼츠·릴스·클립

- **형식: 가게·코스 소개형.** 1차→2차→3차 코스를 실제 사진·영상으로 훑는 구성.
- **금지: 카드뉴스 틀, 자폭 썰·메리 쿠키 같은 곁가지 서사.** (1탄이 이 이유로 반려됐다.)
- 첫 2초에 커버 문구 그대로 회수. 인사말·날씨·로고 인트로 0초. 커버와 첫 2초 자막의 **숫자 집합 일치**.
- 편당 훅·커버에 20분 이상. 증거형 훅은 실측 수치가 있을 때만 — 숫자를 만들지 않는다.
- 유튜브랜딩 4원칙: 타겟 1명 / 첫 2초 / 끝이 보이는 5편 / 통제 숫자는 24h·72h·7d만.
- 클립: 정보태그 + `#오늘클립챌린지` + 전체공개. 3초 미만·단일 사진·동일 내용 재업로드 부적합.

**자막 (1080×1920 ASS, `WrapStyle: 2`, 최대 2줄)**

| | 🍺 대전 청년 | 🐱 삐약 김메리 |
|---|---|---|
| 폰트(libass 패밀리명) | `Pretendard` + Bold=-1 | `NanumSquareRound` + Bold=-1 |
| 크기 | 본문 **68** / 훅 86 | 본문 **64** / 훅 82 |
| 기본색 / 포인트 | `&H00FFFFFF` / `&H0018D8FF` | `&H00F8FFFF` / `&H00B4A5FF` |
| 외곽선·그림자 | 4.5 `&H00101010` / 2.5 `&H80000000` | 4.0 `&H002B2238` / 2.0 `&H66000000` |
| 본문 위치 | 하단 `\an2\pos(540,1380)` | 상단 `\an8\pos(540,280)` |
| 최대 글자 | 줄당 12자 | 줄당 11자 |

- 훅은 `\an8\pos(540,260)`. 메리 훅 종료 **2.00초 뒤 0.05초 간격**으로 본문 시작.
- **릴스 안전영역: 상단 240 / 하단 `y ≤ 1420`** / 좌 96 / 우 140 — 하단 UI에 자막이 걸리면 FAIL.
- 하이라이트는 **줄당 1어절 정적**: `{\c&H0018D8FF&\fscx108\fscy108}석암생소금구이{\r}\N야장에 생삼겹살`
  - 반드시 `{\r}`로 닫는다. `\k`·카라오케·단어별 색 이동 금지(무내레이션엔 타이밍 소스가 없다).
- 파일명(`Pretendard-Bold.otf`)을 Fontname에 쓰면 기본 고딕으로 대체된다.

**자막·내레이션 원칙**: **무자막·무내레이션 우선.** 맛집·일상·메리는 컷 타임코드로만 (cue_gap 검사 끔).
내레이션이 꼭 필요할 때만: 20초 5문장 이하, 10초당 2문장 이하, 문장 18~32자, 문장 사이 0.25~0.4초 무음.
**TTS는 무료만**(Gemini Flash TTS → Edge-TTS), **속도 +0~8%** — +20% 배속은 억양을 눌러 평탄해진다. 문장을 줄여서 맞춘다.
**ASR이 인식한 글자는 자막으로 쓰지 않는다.** 자동 CC 트랙은 업로드 후 삭제.

## 3. 삐약 김메리 (`@s2ongrae` / `@m2ow.mari`)

- **1인칭 '메리 어록' 시점.** 메리가 집사를 하인 취급하는 뻔뻔한 단정형 대사("거기 서. 앞발 내놔."). 집사는 을.
- 15~22초. 3포맷: 취조형(티키타카 3~4턴) / 속마음형(독백 3~4문장) / 먹방+한마디(츄르).
- **AI 영상 생성 금지.** 메리 실제 영상 + TTS 변조 + 자막 + 펀치줌.
- 립싱크는 **실제로 입을 벌린 야옹·"삐약" 컷**(턱 15~25도, 0.3~0.5초)에 첫 음절만 맞추는 제로-AI 방식, 5편 중 2편 한 컷.
- 자막 `NanumSquareRound` 64px, 상단 y280. 카피 톤은 블로그 자폭 톤 그대로. 순백 + 포인트 1단어.
- BGM은 같은 곡 연달아 금지. 이모지는 렌더에서 네모로 깨지므로 문장부호·타이포로 대체.

## 4. 오디오 공통 — `-14.0 LUFS / TP -1.5 dBTP`

```
[현장음] highpass=f=80,lowpass=f=14000,afftdn=nf=-25:tn=1,
        acompressor=threshold=-20dB:ratio=3:attack=10:release=100,
        loudnorm=I=-18:TP=-2:LRA=9, asplit=2
[BGM]   highpass=f=100,loudnorm=I=-24:TP=-3:LRA=7
[덕킹]  sidechaincompress=threshold=0.03:ratio=4:attack=15:release=250:makeup=1
[믹스]  amix=inputs=2:normalize=0:duration=first:dropout_transition=0
[마감]  loudnorm=I=-14:TP=-1.5:LRA=7, alimiter=limit=0.841:level=false:attack=5:release=50
```

- 순서 **라우드노름 → 리미터**. 뒤집으면 피크가 다시 올라간다.
- `asplit=2` 없으면 `matches no streams`로 죽고, `level=false` 없으면 -14가 -13으로 어긋난다.
- 검증: `-14.0 ±0.5 LUFS`, `TP ≤ -1.5`. AAC 192k 변환 뒤에도 다시 잰다.
- 목소리: 대전 청년 `ko-KR-HyunsuMultilingualNeural`(20대 집사 톤) / 메리 `ko-KR-SunHiNeural`. Edge-TTS 실패 시 재시도 후 InJoon 폴백. BGM은 나레이션 뒤 15~16%.
- **TTS 길이 측정 → 영상 길이 자동 확장(+0.45~0.5초 여운) → 말끝 재생 검증** 없으면 렌더 완료로 보고하지 않는다.

## 5. 영상 규격

- **풀프레임 9:16 강제, 검은 레터박스 금지.** 1080×1920 · 30fps CFR · CRF 18 · yuv420p · `+faststart` · AAC 192k/48k.
- 훅 0~2초는 0.8~1.2초 컷 2개, 본문 1.5~2.5초. **3초 이상 정지 금지.**
- 사진 켄번즈 2초 1.00→1.08배, 컷마다 방향 교체. 손떨림은 `vidstabtransform smoothing=12 optzoom=1 zoom=3` + `unsharp`.
- 갤럭시 원본은 BT.2020 HLG HDR → `zscale`+`tonemap=hable` → bt709. VFR 원본은 `fps=30` CFR + `setsar=1` 재인코딩 후 concat(스트림 복사 금지).

## 6. 발행 전 판정 · 표시

- 기계: 자막 안전영역 FAIL / 자막 겹침 FAIL / 줄당 12·11자·3줄·`\k` FAIL / 라우드니스 -15~-13 밖 WARN·TP > -1.0 FAIL / 번역투(`~에 대해`·`~되어진다`·`~에 의해`) WARN.
- 사람: 상호·가격 사실, AI 표시, 워터마크, 음원·폰트 라이선스(OFL만).
- AI 표시: 유튜브=아니오 / 인스타=AI 공개 / 클립=AI 활용 ON. `ai_generated_ratio ≥ 0.5`인 클립은 챌린지 집계 제외.
- 발행 세트는 업로드로 끝나지 않는다: 크로스 업로드 + 썸네일 + 태그 + CC 삭제 + (대전 청년) 블로그 URL 역삽입까지 한 세트.
- 채널별 하루 상한 2건. 자사 스토어 유입 시 `※ 직접 기획·판매하는 자사 스토어 상품입니다` 고정.

## 7. 확인하지 않은 것은 말하지 않는다

- 렌더·발행 결과는 실제 재생·화면으로 확인한 것만 "됐다"고 보고한다. 확인 못 한 건 "확인 못 했다"고 적는다.
- 이 저장소는 공개다. 비밀·개인정보(실명·전화번호·영수증 URL) 금지.
