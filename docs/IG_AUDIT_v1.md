- 우리 판단 두 가지:
  1. **프로필을 자동으로 긁지 않는다.** 인스타 로그인 세션으로 남의·내 프로필을 반복 조회하면 약관·차단 위험이 있고, Graph API 프로필 필드(biography·website)는 토큰 scope 확장 승인이 필요하다. 그래서 **사람이 확인한 값만 넣고** 기계적으로 채점한다.
  2. **게시 주기·편수는 자동 수집 행에서 미리 채운다.** `published_at`이 있는 행이면 '마지막 릴스 며칠 전'과 '30일 편수'를 자동으로 넣는다(같은 영상은 `external_id` 하나로 센다). 없으면 직접 입력한다.

## 채점표 (100점 환산)

가중치는 `seeds/ig_audit_rules.json` 한 곳에 있고, 화면·시험(`test/run.js`)이 같이 읽는다.
점수 = (얻은 점수 합 ÷ 그 트랙 항목의 가중치 합) × 100. 통과=가중치 전부, 주의=절반, 고칠 것=0.

| 항목 | 가중치 | 통과 기준 |
|---|---|---|
| 최근 7일 안에 릴스 1편 | 16 | 마지막 릴스 7일 이내 (8~14일 주의) |
| 30일 안에 릴스 4편 | 10 | 4편 이상 (2~3편 주의) |
| 바이오에 지역·정체 | 14 | 80자 이내 + 트랙 키워드(대전·유성·맛집 / 메리·고양이) |
| 프로필 링크 | 12 | 블로그·스레드·유튜브 중 하나 (링크만 있으면 주의) |
| 하이라이트 3개 | 10 | 3개 이상 (1~2개 주의) |
| 캡션 첫 줄 후킹 | 12 | 질문·숫자·지역명 중 하나 |
| 첫 댓글에 링크·해시태그 | 10 | 달았음 |
| 피드 캐러셀 (대전 청년만) | 8 | 3장 이상 캐러셀 운영 |

- 트랙 A(`daejeon_youth`, `@daejeon_daily`) 가중치 합 **92**, 트랙 B(`ppiyak_kimmary`, `@m2ow.mari`)는 캐러셀을 빼고 **84** — 100점으로 환산한다.
- 등급: 90↑ A · 75↑ B · 60↑ C · 그 아래 D.
- 값을 모르면 0점이 아니라 **주의(절반)** 로 둔다. 모른다고 벌하지 않고, 채우라고 알려 주는 쪽이 맞다.

## 쓰는 법

1. 폰에서 `#/perf` → [인스타] 탭 → 맨 아래 **🔎 인스타 계정 진단**.
2. 바이오·링크·하이라이트·첫 줄·첫 댓글을 넣고 [진단하기].
3. 점수·등급과 함께 **고칠 것이 무거운 순서**로 나온다(먼저 할 것 2개 요약).
4. 값은 이 브라우저 `localStorage`(`contenthub.ig_audit.v1`)에 트랙별로 남는다. 서버로 보내지 않는다.

## 하지 않는 것

- **자동 로그인·자동 조회·자동 댓글·DM 없음.** 인스타 계정 자동화는 계정 정지 위험이 있고 우리 원칙(발행은 사람)과도 어긋난다.
- 점수로 발행을 막지 않는다. 릴스·피드 발행은 지금처럼 성래 님이 한다.
- Graph API 팔로워·도달 같은 실데이터는 `#/perf`의 자동 수집 쪽 몫이고, 이 카드는 프로필 '모양'만 본다.
