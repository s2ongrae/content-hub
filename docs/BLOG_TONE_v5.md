## 1. 실측 — 성래 님 글은 "2줄"이 기본 단위다

| 항목 | 실측값 (8편) |
|---|---|
| 문단(엔터 1회 = 1블록) | 467개 (글당 12~103개) |
| **블록 안 줄바꿈(Shift+Enter)** | **0개** — 한 생각은 끊지 않고 이어 쓴다 |
| 글자수 분포 | ≤20자 **17%** · 21~45자 **52%** · 46~60자 **28%** · 60자+ **3%** |
| 글별 평균 | 33.3 ~ 42.0자 (전체 36.8자) |
| 끝맺음 | `다.` 249 · `!` 17 · `?` 11 — 정중체가 기본 |
| 이모지 | 전체 블록의 10% (소제목·정보 카드에만) |
| 사진 캡션 | `▲ …` 한 줄 |

**왜 2줄인가**: 모바일 360px에서 한 줄이 약 20자다. 32~44자 블록이 딱 2줄로 보인다.
실패 사례(2026-11-21 오전): 모든 문장을 1줄씩 끊어 쓴 초안은 시처럼 보이고 "겁나 재미없어졌다"는 평가를 받았다 — 1줄 남발이 원인.

## 2. 확정 수치 (기계 판정)

| 항목 | 값 |
|---|---|
| 블록 길이 | 하한 **22자** · 목표 **32~44자** · 상한 **54자** |
| 1줄(≤20자) 블록 | 전체의 **20% 이내**, **3연속 금지** |
| 블록 안 줄바꿈 | **0개**. 블록 사이는 빈 줄 1개 |
| 3줄(55자↑) 처리 | 자동 분할 — `! ? .` 뒤 공백 → `, · :` 뒤 → 연결어미(`는데·지만·해서·니까·면서·고·며·서`) 뒤 → 어절 공백 |
| 분할 금지 자리 | 숫자+단위(`1억 1,300만 원`, `-3.5%`, `26,017원`), 고유명사, 괄호·따옴표 안 |
| 분할 후 길이 | 앞 28~38자 + 뒤 22~34자. 한쪽이 15자 미만이면 나누지 않는다 |
| 이모지 | 소제목·정보 카드에만, 전체 10% 이하 |
| 사진 캡션 | `▲ 한 줄` |

## 3. 톤 프리셋 3종

| 프리셋 | 정중체 비율 | 규칙 | 유머 장치 |
|---|---|---|---|
| **자조 찰진** (기본) | 75% | 정중체 + 급발진 반말·구어 25%. `개작살·쪽박·물타기·존버` 허용, 의도적 오타 1글자 | 대전 로컬 비유(성심당 줄·트램·1호선) / 국밥·치킨 환산 / 급발진 펀치라인 |
| 담백 리뷰 | 85% | 정중체 + `~더라고요` 15%. 솔직 단점 1줄·실측 수치 | 가성비 자폭 / 대기시간 비유 / 반전 한줄평 |
| 정보 정리 | 95% | 정중체 + 단정형(`~함`) 5%. 감상은 1줄 | 건조한 팩트 체크 / 예상 질문 차단 / 한줄 요약 비유 |

**면책 1줄**은 그대로 둔다 — `※ 이 글은 제 기록일 뿐 투자 권유가 아닙니다.`

## 4. 무거운 AI 칼럼투 금지 22선

`결론부터 말씀드리자면` · `살펴보도록 하겠습니다` · `알아보도록 하겠습니다` · `주목할 필요가 있습니다` ·
`중요한 시점입니다` · `함께 알아보시죠` · `단순히` · `이는 곧` · `이처럼` · `오늘날 많은 사람들이` ·
`현대 사회에서` · `투자의 세계에서는` · `성공적인 투자를 위해서는` · `무엇보다 중요한 것은` ·
`종합해 볼 때` · `요약하자면` · `결국 핵심은` · `에 대해 이야기해 보겠습니다` · `놀랍게도` ·
`흥미로운 점은` · `한 가지 분명한 사실은` · `마지막으로 강조하고 싶은 것은`

문단 **첫머리**에 오면 잘라낸다(`stripBanWords`). 문장 안에 있으면 그대로 두고 경고만 남긴다.

## 5. 후처리 순서 (실패해도 원문은 남긴다)

1. 블록 안 줄바꿈 → 공백으로
2. AI 칼럼투 제거(첫머리만)
3. 55자↑ 블록 분할
4. 1줄 3연속 → 앞 두 개 병합(44자 이내일 때만)
5. 통계·경고 계산
6. **원문 보존 우선** — USER 블록은 이 과정을 거치지 않는다. 화면에서 사용자가 [2줄 호흡으로 정리]를 누를 때만 적용한다.
