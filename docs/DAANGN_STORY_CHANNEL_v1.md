# 당근 스토리 — 대전 청년 5번째 발행 채널 (v1)

2026-11-18 확정. 근거는 당근 고객센터 FAQ(27248·27249·27250·27251, 2026-11-18 직접 확인)이고,
화면·도구에 들어간 수치는 `seeds/daangn_story_v1.json` 하나를 웹앱과 노트북 도구가 같이 읽는다.

## 0. 한 줄

**쇼츠·릴스·클립을 올린 직후, 같은 영상을 3가지만 손봐서 당근 스토리에도 올린다.**
보상은 영상 1건당 100~1,000원(랜덤) + 월 성과 보상. 스토리 5개·유효 시청 2,000회를 채우면 인플루언서 배지 자격이 생긴다.

## 1. 자격·보상 (당근 공식)

| 항목 | 내용 |
|---|---|
| 자격 조건 | 당월 스토리 **5개 이상**(10초↑·설명 30자↑) + 당월 누적 **유효 시청 2,000회** |
| 알림 | 조건을 채우면 **다음 날 오전 11시** 알림 → **3일 내** 당근폼 프로필 제출 → 배지 |
| 자격 유지 | 매월 스토리 **2개 이상**. 미달 시 다음 달 1일 자동 해지(다시 채우면 복귀) |
| 기본 보상 | 영상 1건당 **100~1,000원** 랜덤(2026-11-01부터 인하, 이전 300~2,000원) · 업로드 즉시 확정 |
| 성과 보상 | 월 집계 → **다음 달 5일 전후**, 월 예산 내 성과 비중 배분 · 월 **1,000원 미만은 미지급** |
| 지급 | **당근페이 필수**(미가입·정지 시 미지급, 소급 없음) |

기본 보상 최소 조건: ① 10초 이상 ② 설명 30자 이상 ③ 소리(음성·음악) 포함 ④ 사진 이어붙이기가 아님(정지 이미지가 1/2 초과면 제외). 1080p 권장.
제작 주체: **본인이 직접 촬영·제작한 영상만**(AI 생성 영상·남의 영상 재가공 불가).

## 2. 발행 규격 (대전 청년)

| 항목 | 확정 |
|---|---|
| 길이 | 15~25초(당근 허용 5~60초) — 숏폼 공방 25초 6비트 원본에서 컷 |
| 해상도 | 1080×1920 세로 · 타 플랫폼 워터마크 제거 |
| 음성 | 현장음 또는 BGM 필수(무음 금지) |
| 자막 안전영역 | 상단 14%·하단 22% 여백, 자막 폭 6.3% 유지(당근 하단 장소태그·설명 UI 회피) |
| 설명 | (협찬 시 첫 줄 `#광고` `#협찬`) + `[동네+가게명] 대표메뉴·가격` 1줄 + 직접 다녀온 팁 1줄 (30자↑, 최대 1,000자) |
| 태그 | 실제 방문 장소 1개 + `#대전맛집 #봉명동맛집 #유성구맛집` 중 2~3개 · 링크 금지 |

**편입 순서:** 쇼츠 → 릴스 → 클립 업로드 직후 → 당근 스토리.
블로그 역삽입 고정댓글은 **당근만 생략**한다(외부 링크 유도 금지).
원본 변형은 3가지만: ① 워터마크 제거 ② 엔딩 CTA("프로필 링크 확인") 컷아웃 ③ 실제 방문 장소 태그.

**메리 트랙은 전량 제외** — 동네 생활권 정보가 아니라서 `daangn_status = SKIPPED` 고정(앱에서도 칩을 그리지 않는다).

## 3. 발행 전 점검 (2026-11-19 개편 — 사람이 체크하지 않는다)

1. **직접 촬영 · 음성 포함 · 10초 이상** — 정지 이미지가 절반을 넘으면 제외
2. **설명 30자 이상 — AI가 쓴 문구 그대로 쓰지 않기** — AI 문구 적발 시 성과 보상 1회 전액 미지급
3. **협찬이면 첫 줄에 `#광고` `#협찬` 표기 · 외부 링크 없음** — 표기 위치 위반은 보상 미지급·자격 해지

> 예전에는 앱 상세 시트에 이 3개를 **체크박스**로 두었지만, "내가 체크해 봐야 의미도 없는 거 아님?"이라는 지적(2026-11-19)으로 걷어냈다.
> 지금은 카드 대본·영상 길이로 **자동 판정**하고, 규칙을 어겼을 때만 카드 분석 탭에 경고 1~3줄이 뜬다(`js/cardPerf.js daangnWarnings`).
> 통과하면 점검 UI 자체가 보이지 않는다. 상세: `docs/CARD_PERFORMANCE_v1.md` §3.

## 4. 위험한 실수 3개

1. 타 채널 CTA 복붙("댓글에 블로그 링크") → 외부 링크 유도로 보상 박탈·제재
2. 협찬 표기 위치 위반·AI 복붙 설명 → 월 성과보상 전액 미지급
3. 같은 장소(가게) 한 달 2회 태그 / 간판만 촬영 → 실적 제외
   (행정동·법정동 태그는 **중복 인정**. 같은 "가게"만 월 1회)

## 6. 리듬·로드맵

## 7. 제미나이 답과 달랐던 점(정정)

- "행정동·법정동 포함 같은 가게 2회 태그는 제외" → 공식 FAQ는 **행정동·법정동 태그는 중복 인정**이다. 같은 "장소(가게)" 태그만 월 1회.
