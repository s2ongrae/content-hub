# 화면 용어 표준 v1 (2026-11-23)

> 이 문서는 **화면에 보이는 말**만 정한다. 시트·GAS·payload의 코드값(`DRAFT`, `READY`, `NEEDS_HUMAN` …)은 그대로 둔다.
> 화면 코드를 고칠 때 여기 있는 이름과 다르면 `test/run.js [12] 화면 용어 표준`이 실패한다.

## 왜 만들었나

승인 탭 빈 상태에 `글감 탭에서 새로 적으면 여기로 옵니다`라고 남아 있었지만 **글감 탭은 없었고**, 새 콘텐츠를 만드는 곳은 `제작`이었다.
사이드바 이름을 바꿀 때 화면 안쪽 문구를 같이 훑지 않아 생긴 불일치다. 이후로는 탭 이름·상태·행동 버튼을 이 표 하나로 맞춘다.

## 탭 (왼쪽 사이드바 · 폰 하단)

| 그룹 | 라우트 | 탭 이름 | 화면 제목 |
|---|---|---|---|
| 매일 | `#/board` | 현황 | `{브랜드} 현황` |
| 매일 | `#/approve` | 승인 | 빠른 승인 |
| 매일 | `#/create` | 제작 | ＋ 제작 스튜디오 |
| 분석 | `#/perf` | 성과 | 📈 성과분석 |
| 분석 | `#/blog` | 블로그 | 📝 내 블로그 |
| 품질 | `#/review` | 검수 | 원고 검수 |
| 품질 | `#/lint` | **발행 점검** | 🔍 발행 전 글 점검 |
| 자산 | `#/series` | 연재 | 🎬 연재 |
| 자산 | `#/knowhow` | **노하우** | 노하우 |
| — | `#/ops` | 관리 | 관리 |

- 숨은 화면(딥링크 유지): `#/capture` = **빠른 카드 만들기**(제작 스튜디오의 `⚡ 빠른 카드`에서 들어간다), `#/post`, `#/create/legacy` = **채널 조립기(예전 화면)**.
- 폰 하단 5칸은 `현황 · 승인 · 제작 · 성과 · 더보기`. 나머지는 더보기 시트.
- `data-route="create"`의 `aria-label="제작 스튜디오"`는 시험이 확인하므로 바꾸지 않는다.

## 비슷한 네 가지의 역할

| 이름 | 라우트 | 한 줄 정의 | 화면 문구 |
|---|---|---|---|
| 승인 | `#/approve` | 검수 대기 원고를 폰에서 한 장씩 읽고 승인/보류/다시 쓰기 | 빠른 승인 |
| 검수 | `#/review` | 발행 전 체크리스트 10항목으로 80점을 넘기는 곳 | 원고 검수 |
| 발행 점검 | `#/lint` | 본문을 9항목·AI 티·첫 400자로 기계 채점 | 발행 전 글 점검 |
| 관리 | `#/ops` | 시트·파일·백업·연결 상태를 보는 시스템 화면 | 시트·파일 점검 |

`점검`만 단독으로 쓰지 않는다. 글을 채점하면 `글 점검`, 시트를 보면 `시트 점검`처럼 대상을 붙인다.

## 상태 배지 (`STATUS_LABEL`)

| 코드값 | 화면 |
|---|---|
| `DRAFT` | 초안 |
| `DRAFTING` · `GENERATING` | 작성 중 |
| `EDITING` | 수정 중 |
| `REVIEW` | **검수 대기** |
| `READY` | **발행 준비** |
| `PUBLISHING` | 발행 중 |
| `PUBLISHED` | 일부 발행 |
| `LINKED` | **발행 완료** |
| `NEEDS_HUMAN` | **직접 확인** |
| `PARTIAL_FAIL` | 일부 실패 |

## 보드 열 (왼쪽 → 오른쪽)

`초안` → `검수·수정` → `발행 준비` → `일부 발행` → `발행 완료` → `직접 확인`

## 행동 버튼

| 하는 일 | 문구 |
|---|---|
| 새 콘텐츠 시작(현황·빈 상태) | ＋ 새 콘텐츠 → `#/create` |
| 메타만 빠르게 적기(제작 안) | ⚡ 빠른 카드 → `#/capture` |
| 승인 대기 원고 통과 | ✅ 승인 |
| 다음 원고로 넘기기 | 보류 |
| 원고를 초안으로 되돌리기 | **다시 쓰기** (예전 `반려`·`다시 고치기`) |
| 80점 검수 통과 | 80점 통과 → 발행 준비 |
| 채널이 다 끝난 카드 정리 | 발행 완료로 넘기기 |

## 카드 상세 탭

`작성본` · `영상 제작` · `성과` · `원본 자료`

## 화면에 쓰지 않는 말

`글감`, `린터`, `제작 스텝퍼`, `원문·메타`, `메타`, `F2`, `M3`, `READY`, `REVIEW`, `PENDING`, `payload`, `역삽입`, `콜드스타트`, `무결성`, `쿼터`, `인제스트`

- `숏폼`은 **포맷 이름**으로만 쓴다(예: `영상 (숏폼·롱폼)`). 채널을 가리킬 때는 `쇼츠`.
- `D.I.A.+`는 처음 나오는 자리에서 `첫 400자 의도 검사`로 풀어 쓴다.

## 길이 상한 (360px 가로 스크롤 0)

- 사이드바 항목: 공백 포함 5자 이내 (`발행 점검`)
- 폰 하단 5칸: 3자 이내
- 카드·시트 버튼: 6자 이내 (`＋ 새 콘텐츠`, `다시 쓰기`)
