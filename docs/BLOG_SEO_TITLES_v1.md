## 2. 점수 — 무엇을 보고 고르나

```
점수 = 트렌드 + 내 실적 + 경쟁 강도 + 동점 흔들기
```

| 신호 | 값 | 근거 |
|---|---|---|
| 최근 4주 vs 직전 4주 | +40%↑ **30** · +15%↑ **20** · ±15% **5** · −15%↓ **−10** | 데이터랩 증감률(모양) |
| 성수기 | **+10** | 지금 값 ≥ 기간 최고의 85% |
| 표본 적음(최고 상대지수 < 10) | **−100 (탈락)** | 한 자리 수 피크는 오름/내림을 말할 표본이 아니다 |
| 내 유입 검색어에 있음 | **+25** | 최근 7일 네이버 통계 |
| 내 순위 11~50위 | **+22** | 반등 여지(리뉴얼) |
| 내 순위 1~10위 | **+12** | 지킬 자리 |
| 블로그 문서 수 | 5만 미만 **+12** · 20만 미만 **+6** · 100만 미만 **0** · 그 이상 **−8** | 네이버 블로그 검색 `total` |
| 이미 쓴 글 제목에 키워드가 있음 | **탈락** (11~50위면 남긴다) | 30일 안 발행글 |

- **축 배분 3/3/2/2**, 후보는 축마다 배분+2개(총 18개)를 날짜에 따라 돌려 가며 본다(같은 키워드가 매일 나오지 않게).
- 동점은 `hash(날짜+키워드) % 7`로 흔들어 같은 점수라도 날마다 순서가 달라진다.

### 데이터랩 숫자를 쓰는 방식 (중요)

공식 문서: `ratio` 는 **"구간별 결과에서 가장 큰 값을 100으로 설정한 상댓값"** — 즉 **주제어(묶음)마다 따로** 정규화된다. 그래서 키워드끼리 100·78 같은 크기를 비교할 수 없다. 이 기능은 **증감률과 성수기 판정(모양)**만 쓴다. (기존 `docs/NAVER_DATALAB_V1.md`의 "같은 요청 안" 표현도 이번에 바로잡았다.)

## 3. 제목 문법

- **18~34자**(공백 포함). 34자를 넘으면 화면이 `n자 · 김` 배지를 단다.
- `{kw}` 자리에 키워드, `{year}` 자리에 연도. 확인하지 않은 가게 이름·가격은 넣지 않는다(지어내지 않기).
- 축별 각도 3~4개를 날짜·키워드 해시로 돌리고, 최근 7일 시트에 같은 제목이 있으면 다음 각도로 넘긴다.
- 금지: `~에 대해 알아보자`(칼럼투), `충격·경악·무조건`(낚시), `최고·완벽`(과장).

| 축 | 각도 예 |
|---|---|
| 맛집·카페 | `대전 냉삼 다녀왔습니다 — 주문한 메뉴와 값` · `유성 맛집 웨이팅·주차까지 적어 둡니다` |
| 생활·정책 | `대전 청년 지원금 2026 신청 조건 정리` · `대전 대형폐기물 해 보고 막힌 데만 적었습니다` |
| 스토어·재테크 | `스마트스토어 첫 주문 첫 달에 실제로 남은 것` · `공모주 청약 일정 시작 전에 알았으면 한 것` |
| 반려묘 | `브리티쉬 숏헤어 두 달 써 보고 남긴 후기` · `고양이 모래 사기 전에 본 것과 산 뒤` |

## 4. 화면

- `#/blog` 맨 위 **오늘의 추천 제목 10** 카드: 축 배지 + 제목 + 근거 한 줄(`▲+28% · 내 14위 · 문서 12만`) + [초안].
- 360px: 처음 4개(축별 1위)만, 나머지 6개는 `나머지 6개 펼치기`. 가로 스크롤 0.
- 제목을 누르면 → `sessionStorage`에 씨앗(`제목·키워드·축·뼈대`)을 두고 `#/create/blog`로 이동. 저장이 막힌 브라우저는 모듈 기억으로 넘긴다(새 탭에 남기지 않는다).
- 스튜디오: `오늘의 추천 제목에서 시작` 패널 + **[메모 뼈대 넣기]**(축별 5줄 질문). 내가 쓴 메모는 건드리지 않고, 뼈대는 내가 고쳐 쓴다. 제목은 `[바로 만들기]`의 1안이 되고 AI 초안이 와도 1안에 남는다.

## 7. 하지 않는 것

- **발행하지 않는다.** 임시저장용 키트까지.
- **AI로 제목을 쓰지 않는다**(아침 배치). AI 호출 실패가 브리핑을 망치고, 재료 없는 AI 제목은 지어낸 말이 되기 쉽다.
- 비밀키·시트 ID·계좌·거주지 상세를 제목·근거·로그 어디에도 넣지 않는다. 축의 키워드는 동네 상권 이름(봉명동·도룡동 등)까지만 쓴다.
