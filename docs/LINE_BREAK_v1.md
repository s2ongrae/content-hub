# 줄바꿈 규칙 v1 (2026-11-22) — 블로그 덩어리 · 클립·쇼츠·릴스 5블록

성래 님이 진미오겹살 클립 설명을 **손으로 고친 것**을 기준으로 확정한 규칙입니다.
이 문서 하나로 웹앱·파이썬 CLI·노트북 프롬프트가 같은 값을 씁니다.

## 1. 왜 바뀌었나 (실측)

| 확인한 것 | 값 |
|---|---|
| 성래 님이 발행한 블로그 1편 DOM | 문단(줄) **108개**, 빈 줄로 나뉜 덩어리 **27개** → 덩어리당 **2~5줄**(가끔 7줄) |
| 한 줄 길이 | 중앙 **34.5자** · 평균 33.3자 · 최대 67자 |
| 빈 줄 위치 | **덩어리 사이에만**. 정보 카드(📍⏰🚗💰) 줄들은 빈 줄 없이 붙어 있음 |
| 우리 자동화(종전) | 모든 줄 사이에 빈 줄(1줄 = 1덩어리) → 모바일에서 **두 배로 벌어짐** |
| 성래 님이 고친 클립 설명 | 3줄 덩어리 → **5블록**(제목 / 요약 1문장 / 정보(한 줄에 한 항목) / 행동 2줄 / 해시태그), 블록 사이 빈 줄 1개, 이모지 없음, 주소는 `도로명+건물번호`까지만 |

## 2. 블로그 본문 규칙

1. **한 줄 = 한 문장.** 22~44자 목표, 상한 **54자**. 넘으면 `. ? !` 뒤에서만 나누고, 숫자+단위·괄호·고유명사·따옴표 안은 자르지 않는다.
2. **2~4줄(최대 5줄)을 빈 줄 없이 붙여 한 덩어리.** 빈 줄은 **덩어리 사이에 한 줄만**.
3. **정보 줄(📍⏰🚗💰📞📌✔)과 ▲ 사진 캡션은 각각 한 덩어리**로 붙인다(안에 빈 줄 금지, 최대 6줄).
4. 한 줄짜리 덩어리를 연달아 두지 않는다(해시태그·소제목·인용구는 예외).
5. 해시태그는 마지막 줄에 한 덩어리로.
6. 1줄(20자 이하) 줄은 전체 20% 이내, 3연속 금지. 금지 문구(AI 칼럼투)는 그대로.

## 3. 설명란(클립·쇼츠·릴스) 규칙 — 5블록

```
① 제목 (34자 이내 · 모바일 피드 접힘선)
(빈 줄)
② 요약 1~2문장 (한 줄 54자 이내)
(빈 줄)
③ 정보 — 영업시간 / 주소 / 주차를 **한 줄에 하나**, 빈 줄 없이
(빈 줄)
④ 행동 유도 2줄 (저장·방문)
(빈 줄)
⑤ 해시태그 한 줄
```

- **네이버 클립**: 이모지 없이 담백하게.
- **유튜브 쇼츠·인스타 릴스·피드**: 정보 줄에만 `⏰ 영업` `📍 주소` `🚗 주차` 이모지.
- 주소는 **도로명 + 건물번호까지만**(`103·104호` 같은 호수는 뺀다) — 성래 님 클립 수정본 그대로.
- 한도: 클립 3,000자 · 쇼츠 5,000자 · 릴스/피드 2,200자.

## 6. 제미니 협의 결론 (2026-11-22)

- 줄 상한 **54자 유지**(실측 최대 67자는 모바일에서 3줄 '벽돌 텍스트'가 됨), 덩어리 **일반 2~4줄·최대 5줄**, 정보 블록 최대 6줄.
- 제목 상한은 제미니가 32자를 권했지만 **성래 님 실제 클립 제목이 33자**여서 **34자**로 확정(근거가 사용자 실측).
- 붙여야 하는 덩어리의 기계 판정 신호: `📍⏰🚗💰📞📌✔` 시작 = 정보, `▲△` 시작 = 캡션, `#` 시작 + `#` 2개 이상 = 해시태그.
- 린터 우선순위: ①빈 줄 3연속/비율 50% 초과 ②보호 토큰 내부 개행 ③제목 초과 ④줄 초과 ⑤정보·캡션 분리 ⑥고아 1줄 덩어리 남발 — 모두 `lintRhythm`/`lintDesc` 에 들어감.
