# 카드 1장 통합 성과 대시보드 (v1)

2026-11-19 사용자 지시로 개편. 제미나이 「콘텐츠 허브 프로젝트 관리」 고정방 2턴 협의 후 확정.

> 사용자: "카드 하나에 종합 성과분석도 있고 카드 하나 안에 각 채널별 성과도 보고 그렇게 해놔야지 너무 짜치게 만들어놨는데?"
> "콘텐츠 허브에 뭐 당근 점검 이딴 건 왜 넣어 … 내가 체크해 봐야 의미도 없는 거 아님? 그리고 당근은 올린 거 링크 따거나 그런 거 못 해?"

## 0. 한 줄

**카드 한 장을 열면 그 콘텐츠의 총 조회·총 반응과 채널 6칸 성과가 바로 보이고, 사람이 체크하던 '당근 점검'은 자동 판정으로 바뀐다.**

## 1. 바뀐 것 / 없어진 것

| 영역 | 이전 | 이후 |
|---|---|---|
| 보드 카드 | 상태 칩만 | 발행된 카드에 `👁 총 조회 · ❤️ 총 반응` 미니 뱃지 |
| 카드 상세 분석 탭 맨 위 | '다음 할 일'부터 | **종합 성과 4칸**(총 조회·총 반응·확정 보상·게시 완료) + 채널 비중 막대 |
| 채널 표현 | '채널별 현황'(상태+링크) 목록 + 성과는 #/perf·#/post에 따로 | **채널 타일 6칸**에 상태·대표 숫자·보조 숫자·추이·바로가기·입력까지 한 칸 |
| 당근 '올리기 전 점검' | 체크박스 3개를 사람이 체크(localStorage) | **삭제.** 대본·영상 길이로 자동 판정, 어겼을 때만 경고 1~3줄 |
| 당근 수익화 트래커 | 카드 안 긴 카드(진행 바 2개+안내문) | 당근 타일 하단 1줄(`이번 달 3/5편 · 1,450/2,000회`) + 월 KPI는 성과 화면 유지 |
| 당근 링크 | 넣을 곳이 없어 비어 있음 | 타일 안 **공유 링크 붙여넣기 1칸** → 저장하면 `daangn_status=UPLOADED` |
| '성과 탭 열기' 버튼 | 상세 하단 | 삭제(같은 화면에서 다 본다) |
| 품질 점검 | 펼친 목록 | `<details>`로 접어 둠 |

## 2. 계산 규칙

- **대표 숫자**: 블로그=누적 조회, 쇼츠=조회, 릴스=조회, 피드=도달, 클립=조회(직접 입력), 당근=유효시청(직접 입력).
- **총 조회** = 위 대표 숫자의 합(단위가 섞임 → 화면에 1줄 주석 고정).
- **총 반응** = 좋아요+댓글+저장+공유(자동 수집) + 당근 좋아요(입력). 블로그 공감·댓글은 수집 경로가 없어 **세지 않는다**(0으로 속이지 않음).
- **추이**: 자동 수집 채널은 직전 수집 대비 `↑%`, 손으로 넣는 채널(블로그·클립·당근)은 입력 간격이 불규칙해 `↑ 증감분`으로 표시. 비교할 이전 값이 없으면 숨긴다.
- **같은 값 중복 금지**: 자동 수집은 영상·채널별 최신 한 줄, 손 입력은 카드·채널별 최댓값(누적값). 여러 날을 더하지 않는다.
- **모르는 값은 null** → 화면이 '수집 전'을 고른다. 0으로 표시하지 않는다.

## 3. 당근 자동 점검 (사람이 체크하지 않는다)

카드 대본(`payload.daangn`)이 있을 때만 판정한다. 통과하면 아무것도 보이지 않고, 어긴 항목만 보인다.

| 규칙 | 판정 | 경고 문구 |
|---|---|---|
| 길이 10초 이상 | `duration_sec < 10` | 영상 N초 — 10초 이상이어야 보상 인정 |
| 설명 30자 이상 | 글자수(공백 포함) < 30 | 설명 N자 — 30자 이상이어야 보상 인정 |
| 설명에 외부 링크 없음 | `https?://` 포함 | 설명에 외부 링크가 있어요 — 당근은 링크 유도를 금지합니다 |
| 협찬이면 첫 줄 `#광고`·`#협찬` | sponsored && 미표기 | 협찬 카드인데 설명 첫 줄에 #광고·#협찬 표기가 없어요 |

대본이 없는 카드(발행 기록만 있는 카드)는 판정 자체를 하지 않는다 — 의미 없는 소음이므로.

## 4. 당근 링크 = 기록·바로가기 (실측 한계)

- 당근 스토리는 **앱 전용**이다. 웹(daangn.com)에는 중고거래·동네생활만 있고 스토리 페이지가 없다(`/kr/stories` 404 확인). 공개 API도 없다.
- 앱의 '공유'로 만든 링크는 앱을 여는 딥링크이며, 웹에서 조회수·좋아요를 읽을 수 없다.
- 그래서 링크는 **기록·바로가기**로만 저장한다. 붙여넣으면 게시 완료로 표시하고, 숫자(유효시청·좋아요·보상)는 앱 화면을 보고 타일에서 직접 넣는다. 화면 조회수 ≠ 유효시청(본인·반복 시청 제외).
