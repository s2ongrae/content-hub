# 숏폼 글자 디자인 · 구간 제목 · 미리보기 (Phase 1)

자막의 **색·외곽선·그림자·검정 박스·위치**와 **구간 제목·배지**를 허브 화면에서 고르고, 같은 값을 노트북이 ASS 로 구워 MP4 에 넣는다.
기획·실측은 `work/숏폼-글자디자인-UI/기획안.md`(2026-11-25), 사용자 결정은 `[#50106] 오케 다 진행 / 미리보기도 넣어`.

## 어디에 있나

- 화면: 카드 상세 → **제작** → ④ 클린 마스터 안의 `글자 디자인 · 구간 제목 (자막 색·박스·위치)` 패널
  (채널 템플릿 바로 아래, 오더 보내기 버튼 위). ⑤⑥ 이 아니라 ④ 인 이유: 이 값은 ④ 의 `content_render` 오더가 굽는다.
- 값: 카드 payload `studio.formats.video.design` **한 곳에만** 둔다(사본 금지 — 두 벌이 갈라지는 사고 방지).
- 오더: `payload_source:'drive'` 만 실어 보낸다. 큐(허브 `Orders.gs` → 포털 `Code.gs`)는 payload 를 **고정 키로 다시 만들기** 때문에
  디자인을 큐에 실으면 조용히 사라진다(템플릿·컷·모션에서 세 번 겪은 사고). 노트북이 `get_content_detail` 로 카드에서 읽는다.
- GAS·포털 변경 **0건**. 재배포도 0회.

## 값 모양

```json
"design": {
  "v": 1,
  "roles": {
    "caption": { "preset": "base", "font": "Pretendard", "color": "#FFFFFF",
                 "outline": { "color": "#111111", "px": 3 },
                 "shadow": { "on": true, "alpha": 55, "x": 2, "y": 5, "blur": 6 },
                 "box": { "on": false, "alpha": 70, "radius": 18 },
                 "pos": { "x": 0, "y": 1419 } },
    "title": { "font": "Pretendard", "color": "#FFE84D", "size": 78, "pos": { "x": 0, "y": 372 } },
    "badge": { "font": "Pretendard", "color": "#FFFFFF", "size": 42, "pos": { "x": 0, "y": 454 }, "pill": true }
  },
  "segments": [ { "start": 0, "end": 5.6, "title": "돈키호테 쇼핑리스트 2단", "badge": "이번엔 일본 약국템만" } ]
}
```

- 좌표는 **1080×1920 픽셀**. 자막 `pos.y` 는 **밑단**(ASS `\an2` 의 pos y, 기본 1419 = 0.739×1920), `pos.x` 는 가운데에서의 오프셋(0 = 가운데).
- **기본값 = 지금까지의 출력.** 아무것도 안 건드리면 `design` 키가 저장되지 않고(`null`), 노트북도 예전 코드 경로를 그대로 탄다 → 기존 카드·오더 회귀 0(시험이 바이트 동일로 고정).
- 상한: 구간 6개 · 제목 20자 · 배지 16자 · 최소 0.3초. 값은 허브·노트북이 같은 규칙으로 정규화한다(`js/designModel.js` ↔ `lib/design.js`).

## 프리셋 5종 (seeds/video_template.json `design.presets`)

| id | 이름 | 요지 |
|---|---|---|
| `base` | 기본 돈키호테 | 흰 글씨 · 3px 외곽선 · 옅은 그림자(지금까지) |
| `clean` | 깔끔 화이트+그림자 | 외곽선 0 · 번짐 9 그림자 — 밝은 화면에서는 묻힐 수 있어 경고 |
| `neon` | 네온 옐로우 | 노란 글씨 + 번지는 빛 |
| `box` | 자막 검정 박스 | 반투명 검정 판(70%·둥글기 18px) 위 흰 글씨 |
| `mint` | 민트 포인트 | 민트 글씨 + 진한 테두리 |

**가독성 하한**(막지 않고 경고만): ① 외곽선 2px 이상 ② 박스 진하기 40% 이상 ③ 그림자 70%+번짐 4 이하 중 하나.

## 박스는 `\p1` 둥근 사각형 한 장

`BorderStyle=3` 은 두 줄이 한 덩어리로 그려지긴 하지만 줄마다 폭이 달라 **좌우가 계단처럼 꺾인다**(기획안 3-2①).
그래서 우리가 이미 계산하는 줄바꿈(`wrap_ko`)에서 **가장 긴 줄 폭**으로 둥근 사각형 한 장을 깔고(`\p1`, 둥글기 그대로) 텍스트를 위 레이어에 얹는다.
- 박스: layer 0 / 글자: layer 1, 같은 `\fad(80,60)`.
- alpha = 100 − 진하기. 70% → `\1a&H4D&`.

## 구간 제목·배지

- **컷이 아니라 초(타임라인)** 기준 — 나중에 컷 순서를 바꿔도 제목이 어긋나지 않는다.
- 오프닝 훅(0~2.4초)과 겹치면 **훅 끝에서 시작**한다(중앙 훅 박스와 충돌 방지).
- 구간 제목을 1개라도 쓰면 상단 **2줄 임팩트 제목은 자동으로 꺼진다**(같은 자리에서 겹침). 화면에도 그렇게 안내한다.
- 제목은 `\an5` 가운데 정렬(기본 Y372 — 브랜드 뱃지 y244~322 아래), 배지는 검정 알약(`\p1`, 둥글기 = 높이/2) 위 흰 글씨.
- `자막 범위로` = 카드 자막 큐의 시작·다음 큐 시작으로 스냅.

## 미리보기 (웹 캔버스)

- 1080×1920 캔버스를 CSS 로 360px 폭까지 줄여 그린다. 내부 해상도는 그대로라 MP4 와 같은 좌표·같은 수치다.
- 폰트: `font/Pretendard-Bold.woff2`(서브셋, SIL OFL 1.1 — `font/OFL.txt`) + `@font-face`. CSP 는 이미 `font-src 'self'`.
- **끌어서 옮기기**: 지금 고른 탭(자막/구간 제목/배지)의 위치가 움직인다. 자막 밑단 1419·제목 372 근처에서 살짝 붙는다.
- **배경**: 이 기기에서 고른 사진, 또는 영상의 한 프레임(`currentTime≈3초` — 페이드 때문에 0초는 글자가 투명하다). 파일은 브라우저 메모리에만 있고 **어디에도 올리지 않는다**.
- 버튼: `이 위치를 모든 자막에 적용`(자막 위치는 원래 한 벌이라 저장 확인), `디자인 초기화`(구간은 유지).

## 노트북 쪽

- `lib/design.js` — 정규화·검사·타임라인·ASS 조각(순수 함수, 파일·ffmpeg 없음).
- `lib/captions.js` — `opts.captionStyle` 이 있으면 `\an2\pos()`·`\shad/\blur`·박스 레이어로 굽는다. 없으면 예전 줄 그대로(바이트 동일).
- `lib/template.js` — `ctx.design` 의 구간을 `SegTitle`/`SegBadgeBox`/`SegBadgeText` 이벤트로. 구간 제목이 있으면 `Title`(2줄)은 건너뛴다.
- `lib/render.js` — 카드에서 design 을 읽고(`studio.formats.video.design`), `report.design`(적용값·구간 목록·경고)과 `report.design_warnings` 를 남긴다.
- 재인코딩 증가 0 — 구간·박스 모두 자막 굽기 **한 번**(같은 ASS)에 들어간다.

## 커스텀 폰트 (2026-11-27, P0 — 레이 님 결정)

레이 님이 두 가지를 정했다(부이 전달 `Q-20261127-125239-4t3m`): **커스텀 폰트 업로드**와 **재배포 가능한 라이선스만 허용**.

### 어디에 저장하나

- 드라이브 `ContentHubOS_Fonts/` **비공개** 폴더 한 곳(영상·사진의 `ContentHubOS_Uploads/<content_id>/` 와 별개 — 모든 카드가 같이 쓴다).
- 올리기는 영상과 같은 2MB 조각 경로다: `font_put`(조각) · `font_list`(목록) · `font_fetch`(조각 받기 — 화면 미리보기·노트북) · `font_delete`.
- 목록·라이선스는 폴더 안 `_fonts.json` 한 파일에 모은다(`{name, label, license, bytes, parts, updated_at}`).
- 같은 이름으로 다시 올리면 옛 조각을 지우고 새로 시작한다(멱등). 보관함 40종·한 벌 20MB 까지.

### 허용 규칙 (서버가 최종 판정)

| 라이선스 | 받나 | 비고 |
|---|---|---|
| OFL-1.1 · Apache-2.0 · MIT · CC0-1.0 · CC-BY-4.0 · PD | 받는다 | CC BY 는 영상·설명란 출처 표기 |
| 상용·데스크톱 라이선스(산돌·윤디자인 등) | 받지 않는다 | 파일 보관 자체가 재배포 — 영상에 글자로 찍는 것만 허용 |
| 개인용 무료(상업·재배포 금지) · 라이선스 모름 | 받지 않는다 | 무료로 받았다고 재배포가 되는 것이 아니다 |

- 확장자 `ttf`·`otf`·`woff2` 만. **첫 4바이트 서명**(`\x00\x01\x00\x00`·`true`·`OTTO`·`wOF2`·`ttcf`)으로 폰트 파일인지 확인한다 — 확장자만 바꾼 파일은 거절.
- 화면은 라이선스를 고르고 "다시 배포해도 된다" 확인에 체크해야 올리기가 열린다(`js/designModel.js` `checkFontLicense`).
- 두 벌의 상수가 갈라지지 않게 `test/run.js` [15b] 와 `gas/test/run.js` [V2b] 가 목록·상한을 대조한다.

### 값 · 미리보기 · 노트북

- 역할의 `font` 값은 **파일 이름**이다: 기본 `"Pretendard"`, 커스텀 `"Miryung-Bold.otf"`. 이름이 그대로라 노트북이 파일만 찾으면 된다.
- 모르는 값(경로·다른 확장자·이상한 글자)은 `normalizeFontRef` 가 `Pretendard` 로 되돌린다 — 렌더가 깨지지 않게.
- 미리보기는 `font_fetch` 로 바이트를 받아 `FontFace` 에 `customFontAlias()` 별명으로 등록해 그린다(파일마다 별명이 달라 섞이지 않는다).
- **woff2 는 화면 미리보기용**이다 — ffmpeg/freetype 이 woff2 를 풀지 못하므로 MP4 에 굽고 싶으면 같은 폰트의 ttf·otf 를 올려야 한다(화면 경고 `font_woff2`).
- 노트북 `lib/design.js` 는 아직 `font` 값을 Pretendard 로만 다룬다 — 커스텀 폰트 굽기(`RENDER_FONTS_DIR`·`fontfile=`)는 @노트북 몫으로 남아 있다.
