# 초안 카드의 '내용' — 어디에 저장되고 어디서 보이나 (2026-11-19)

대표 지적: "콘텐츠 허브 현황 초안에 내용도 있어야지 그런 것도 하나도 없고, 이걸 보고 뭔 내용인 초안인지 어떻게 알아."
→ 원인은 두 가지였다. **① 화면이 내용을 안 보여 줬다**(상세가 '분석' 탭으로 열리고 본문은 '원문·메타' 안에 숨어 있었다). **② 애초에 본문이 허브에 없는 카드가 있었다.**

## 1) 본문은 어디에 있나 — Drive payload 의 채널 키

`Contents` 시트는 제목·상태·채널 URL만 갖는다. 본문·대본은 카드별 Drive JSON(`payload_file_id`)의 채널 키에 있다.

```json
{
  "blog":    { "title": "...", "body": "본문…", "hashtags": ["#대전청년"], "draft_url": "..." },
  "shorts":  { "title": "...", "body": "대본·캡션…" },
  "reels":   { "title": "...", "body": "캡션…" },
  "ig_feed": { "title": "...", "body": "카드뉴스 장표 문구…" },
  "clip":    { "title": "...", "body": "설명…" },
  "daangn":  { "title": "...", "body": "설명 30자 이상…" }
}
```

- 글 덩어리는 `body`(또는 `script`·`caption`·`text`)에 넣는다.
- 저장은 `update_content` 의 `patch`(최상위 키 통째 교체)만 쓴다. 새 액션·새 열 없음.
- 화면(카드 상세 → **작성본**)에서 직접 붙여넣어 저장할 수도 있다.

## 2) 화면이 하는 일 (v2-m25)

| 위치 | 무엇을 보여 주나 |
|---|---|
| 보드 카드('초안·작성 중·내용 확인·수정 중') | 본문 첫 두 줄. 본문이 없으면 "본문 아직 없어요 — 눌러서 붙여넣기" |
| 카드 상세 | 발행 전 카드는 **작성본** 탭으로 바로 열린다. 채널 칩(● = 작성본 있음) · 제목 · 글자수 · 본문 문단 · 해시태그 |
| 작성본 버튼 | [본문 복사] [임시저장 열기(주소가 있을 때)] [고치기] · [내용 확인으로 보내기] · [고칠 점 적기] |
| 본문이 없을 때 | "○○ 작성본이 아직 없어요" + 임시저장 메모(어디서 온 카드인지) + [＋ 본문 붙여넣기] |

## 3) 앞으로 초안을 만들 때 지킬 것

1. 초안 카드를 만들면 **제목만 두지 말고 본문(또는 대본)을 payload 에 같이 넣는다.** `blog_title`·`place_name` 만 있는 카드는 화면에서 "본문 아직 없어요"로 보인다.
2. 네이버 임시저장 글은 **고유 URL 이 없다.** 글쓰기 편집기로 열어야 본문이 보이는데, 열었다가 자동저장이 겹치면 대표가 쓰던 글이 덮일 수 있으니 **임의로 열지 않는다.** 대표가 [작성본 붙여넣기]로 옮기거나, 복사해 준 본문을 피클이 `patch` 로 넣는다.
3. 이미지·사진 자리는 본문에서 `[사진: 설명]` 형태로 적는다(그대로 두면 발행 때 사진 위치를 찾기 쉽다).
